- по тер. признаку (отличие - оборудование):
	- Локальные (LAN - домашние)
	- Ведомственные(corporative/interprise)
	- MAN (городские сети)
	- Региональные (мтс, лайф, а1)
	- Глобальные (WAN)
- по скорости:
	- Низкоскоростные сети (меньше/равна 10 Мбит/c)
	- Средний диапазон (10<…<1Гбит/с)
	- Высокоскоростные (1Гбит<…<10Гбит)
	- Сверхвысокоскоростное (>10Гбит/c)
- по среде передачи данных
	- Проводные
	- Беспроводные
- по способу организации (характерен для локальных и корпоративных сетей)
	- Одноранговые (все станции в сети имеют один ранг)
	- Сети на основе сервера
- по топологии
	- Шина (устройства с сетевым вз-ем)
	- Звезда (все уст-ва подключены к центральному уст-ву)
	- Кольцо (все уст-ва последовательно соединены в кольцо и гоняют по кругу)
	- C коммутацией каналов
	- C коммутацией пакетов
